Real iOS on an Android phone

xlamiOS boots Apple's iOS 16.7 on a POCO F6 (peridot, Snapdragon 8s Gen 3). It is the real thing: Apple's kernel built from its open-source code, and the system files of an iPhone X, with a handful of settings changed so it boots on foreign hardware. There is no emulator or launcher involved, and no Android running underneath.

This is a research project, not a daily driver. Apple's security model is mostly switched off, most radios are missing, and the iOS root volume lives in the userdata partition, so it erases Android's user data.

Where it is right now

Works

  • The iOS userland runs: launchd, the system daemons, backboardd and SpringBoard
  • Lock screen, home screen, Control Center, notification center, Settings
  • A software-rendered 1125 × 2436 logical surface, presented to iOS as an iPhone X panel
  • Power and volume up/down as HID consumer keys, read from the PMIC over SPMI
  • The internal UFS holds the iOS root volume: a journaled HFS+ filesystem, read/write
  • The touch panel's registers are read over bit-banged SPI (Goodix BerlinD, 9916R)
  • All 8 CPU cores, 16 KiB pages, GICv3, timers, SMP bring-up
  • The upper DDR bank as system memory, with a private DMA arena for the display and the SPI engine

Missing

  • GPU: there is no driver, so every frame is drawn by the CPU
  • Wi-Fi, Bluetooth, cellular, audio, camera, sensors
  • Secure Enclave, App Store, Apple ID
  • The touch path exists, but it has not been exercised by a finger yet

Have a POCO F6?

Then you don't need to port anything. The build steps are in the README on GitHub: the kernel is built by GitHub Actions, a payload is assembled from it, and tools/peridot-cycle.py then runs a whole session unattended. You need an unlocked bootloader, a Linux PC and a GitHub account. Nothing is flashed — the image is booted temporarily with fastboot boot — but the iOS root volume goes into userdata, which erases your Android user data.

Every boot, crash and fix is written down in NOTES.md, including the ones that failed.
